## ストアの掲載情報

### 名前

```
Amazonize Rakuten
```

### 概要（manifest の description。132文字まで）

```
楽天市場をAmazon風のシンプルなUIに。商品ページにAmazonでの価格を表示。クーポン獲得・かご合計・最適クーポン自動適用・キャンペーン自動エントリー。
```

### 説明

ストアの説明欄はMarkdownを解釈しないので、記号は「■」「・」だけにしてある。

```
楽天市場の商品ページを、Amazonのように見やすい3カラムに組み直す拡張機能です。かごの合計金額、いちばん得なクーポンの自動適用、キャンペーンの一括エントリーなど、楽天でのお買い物の「めんどう」を減らします。

■ 商品ページを見やすく
・画像／商品情報／購入エリアの3カラムに再構成。長い商品説明をスクロールしなくても、そのままかごに入れられます
・説明文の中に埋もれた商品画像を左のギャラリーへ集めます。同じ画像は1枚にまとめます
・画像をクリックで大きく表示。←→キーで次の画像へ
・商品動画もギャラリーに並べます。勝手に再生されず、再生ボタンを押したときだけ再生します
・商品とショップのレビュー評価を商品名の下に表示
・同じ商品がAmazonではいくらかを、楽天の価格のすぐ下に表示（Amazon側の商品名・評価と、検索結果へのリンクつき）
・JANコードが一致した商品は「JANコード一致」、商品名から探した商品は「参考」と表示します

■ かごの合計金額
・複数のショップにまたがる商品合計・送料・獲得予定ポイントを、ひとつのパネルにまとめて表示
・ポイントを差し引いた「実質いくらか」も表示
・数量を変えるとすぐに追従。ショップ別の内訳も確認できます

■ クーポン
・商品ページに出るクーポンを、クーポンページへ移動せずにその場で獲得
・獲得したクーポンは、ツールバーのボタンから一覧で確認できます
・注文確認画面で、使えるクーポンの中から「この注文でいちばん多く引けるもの」に自動で切り替え（割引率ではなく割引額で比較）
・適用前に確認する設定にもできます
・注文の確定ボタンは絶対に押しません。確定は必ずご自身で行ってください

■ キャンペーンの一括エントリー
・ツールバーのボタンから、楽天トップページに出ているキャンペーンを調べて、未エントリーのものにまとめてエントリー
・楽天トップページを開いたときにも、楽天を開いていないときにも、裏で自動的に調べてエントリーします（12時間おき。設定でOFFにできます）
・調べるときにタブは開きません。画面もタブ欄も変わらないので、作業の邪魔になりません
・楽天のエントリーボタンと同じ仕組みでエントリーし、エントリー済みになったことを確かめてから記録します
・自動で判断できなかったキャンペーンは「要確認」として一覧で目立たせます
・楽天には無い「エントリー済みの一覧」をあとから確認できます

■ 設定
ツールバーのアイコンから、機能ごとにON／OFFを切り替えられます。

■ プライバシー
・表示を変えるのは楽天市場（rakuten.co.jp）のページだけです
・Amazonでの価格は、見ている商品の商品名またはJANコードでAmazonの検索結果を読んで表示します。Amazonへはログイン情報（Cookie）を送りません

・設定、キャンペーンの記録、獲得したクーポンの一覧はブラウザ内（chrome.storage）にだけ保存します
・クーポンの取得・獲得やレビュー評価の取得は、楽天市場のサーバーとの間でだけ行います

■ ご注意
・本拡張機能は個人が開発したもので、楽天グループ株式会社、Amazon.com, Inc. およびその関連会社とは一切関係ありません
・楽天市場のページの作りが変わると、一部の機能が動かなくなることがあります。そのときは設定から該当の機能をOFFにすると、元の表示に戻ります

■ 姉妹作品
```

## プライバシーへの取り組み

### 単一用途の説明

```
楽天市場（rakuten.co.jp）でのお買い物を快適にするための拡張機能です。商品ページを見やすく組み直し、かごの合計金額の表示、クーポンの獲得と最適なクーポンの適用、キャンペーンへのエントリー、同じ商品のAmazonでの価格の表示を、楽天市場のページ上で行います。
```

### 権限が必要な理由

**storage**

```
機能ごとのON/OFF設定と、キャンペーンのエントリー結果（エントリー済み一覧）、キャンペーンの自動スキャンを最後に実行した時刻、商品ページで獲得したクーポンの一覧（クーポン名・ショップ名・商品名・商品ページのURL）、レビュー評価の一時的なキャッシュを保存するために使います。保存先はユーザーのブラウザ内だけです。
```

**alarms**

```
キャンペーンの自動エントリーを、ブラウザで楽天市場を開いていないときにも定期的（12時間おき）に実行するために使います。ほかの用途では使いません。
```

**declarativeNetRequestWithHostAccess**

```
楽天市場のクーポンAPI（api.coupon.rakuten.co.jp）は、Referer が商品ページでないとログイン中でも未ログインとして応答します。拡張機能のバックグラウンドから商品ページのクーポンを取得・獲得するとき、その通信に限って Referer を商品ページのURLに設定するために使います。タブに属さない通信（拡張機能自身の通信）だけが対象で、ユーザーが開いているページの通信は変更しません。
```

**ホスト権限（https://*.rakuten.co.jp/*）**

```
楽天市場の商品ページ・検索結果・かご・注文確認・キャンペーンの各ページで表示を組み直し、クーポンとキャンペーンの処理を行うために必要です。
```

**ホスト権限（https://www.amazon.co.jp/*）**

```
楽天市場の商品ページで「同じ商品がAmazonではいくらか」を表示するために使います。商品のJANコードまたは商品名でAmazonの検索結果ページを1回読み、価格・商品名・評価を取り出して楽天のページに表示するだけです。Amazonのページの表示は変更せず、ユーザーのAmazonアカウントにも触れません（Cookieを送らずに取得しています）。
```

### リモートコード

```
いいえ、リモートコードは使用していません。
```

すべてのスクリプトは拡張機能のパッケージに含まれている（外部のJSを読み込む・eval する箇所は無い）。

### データの使用

- 収集するユーザーデータ: **どれにもチェックしない**
  - かごの金額やクーポンは、ページの中で読んで表示するだけで、端末の外（開発者のサーバー）へ送らない。
  - Amazonへの通信は、楽天の商品ページから作った検索語（JANコードまたは商品名）で検索結果を読むだけ。Cookieを送らないので、ユーザーのAmazonアカウントとは結び付かない。
  - 楽天のAPIへの通信は、ユーザーが楽天市場で普段行うのと同じ、楽天とのやり取り。
  - 注文確認のページの状態には氏名・住所・電話・メール・カード下4桁が入っているが、`state-bridge.js` が金額まわりのキーだけを抜き出し、それ以外は拡張側にも渡さない。
- 次の3点に同意する:
  - 承認されている用途以外で、ユーザーデータを第三者に販売、転送しない
  - アイテムの単一用途と関係のない目的で、ユーザーデータを使用、転送しない
  - 信用力を判断する目的または融資目的で、ユーザーデータを使用、転送しない

## 審査で気をつけること

- **名前に他社の商標（Amazon / Rakuten）が入っている。** ストアのポリシーでは、提携や公式であるかのように見える使い方は「なりすまし」「知的財産権の侵害」として却下されうる。説明の末尾に「楽天グループ・Amazonとは関係ない」旨を入れてあるが、それでも名前で弾かれる可能性はある。弾かれたら「楽天市場をシンプルに」のような、商標を名前の先頭に置かない名前に変える（説明の中で「楽天市場向け」「Amazon風」と書くのは記述的な使用として通ることが多い）。
- **スクリーンショット1・2とマーキーには実在の店舗の商品画像が写っている**（保存した hoyu のページ）。気になるなら `STORE_ITEM=<別の保存名> node tools/store-images.mjs` で差し替える。
- 「検索結果の広告を目立たなくする」は現状なにもしない（README の既知の制約）ので、説明には書いていない。
